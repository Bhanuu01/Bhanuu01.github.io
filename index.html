Flagship case study

Fused Linear Attention

CUDA kernel exploration for transformer inference, focused on fusing QKV projection and attention to reduce HBM traffic and reason more clearly about GPU bottlenecks.

The useful part of this project was not just the final bandwidth result. It was learning how to profile a GPU path carefully, validate the kernel against PyTorch references, and understand where the next bottleneck still remained after the first optimization worked.

Profiled on H100, validated across reference tests, and used as a practical study in how measurement changes CUDA optimization decisions.
11–55% HBM bandwidth reduction H100 evaluation

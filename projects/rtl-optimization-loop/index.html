RTL Optimization Loop

An AI-assisted verification loop for synthesis, timing analysis, and iterative patch generation.

Verilator · Yosys · OpenSTA · Python · LLM-assisted tooling

This project sits a little differently from the others on the site, but it fits the same pattern: turn a sequence of manual engineering checks into a workflow with clearer feedback and shorter iteration cycles.

What it does

The loop automates synthesis, verification, timing analysis, and LLM-guided patch generation using Verilator, Yosys, and OpenSTA. The goal is not to replace hardware reasoning but to reduce repeated mechanical work so debugging and optimization become more structured.

Why it matters

I included this project because it reflects another side of my interests: tooling and developer loops. The motivating question is the same one I bring to backend or ML systems work: which parts of the loop are actually high-signal, and which parts should be automated so the human can think more clearly?
